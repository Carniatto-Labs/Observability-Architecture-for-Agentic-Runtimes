# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues.

Until a dedicated security contact is published, report vulnerabilities privately to the Carniatto Labs maintainers through the contact information listed in the repository profile or organization website.

Please include:

- a description of the issue;
- potential impact;
- steps to reproduce, when applicable; and
- any suggested mitigation.

We will acknowledge reports, assess impact, and coordinate disclosure responsibly.
